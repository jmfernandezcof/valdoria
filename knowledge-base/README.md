# Valdoria Knowledge Base

Repositorio de información turística y de marca para alimentar el avatar digital de Valdoria Hotel (LiveAvatar/HeyGen).

## Estructura
- `hotel.md`: Datos clave sobre Valdoria Luxury Resort & Spa (posicionamiento, servicios, experiencias).
- `tarancon.md`: Guía turística de Tarancón y alrededores inmediatos.
- `castilla-la-mancha.md`: Información general de Castilla-La Mancha orientada a visitantes.
- `heygen-brief.md`: Pautas y mensajes clave para configurar el avatar conversacional.
- `heygen-full-prompt*.md`: Versiones del prompt histórico de Val; revisar y adaptar el contenido al contexto/voice agent de LiveAvatar antes de activar el avatar.

## Uso sugerido
1. Consulta los ficheros temáticos para obtener contexto específico.
2. Integra los mensajes prioritarios de `heygen-brief.md` en el guion base del avatar.
3. Actualiza la knowledge base cuando cambien experiencias, eventos o promociones.
